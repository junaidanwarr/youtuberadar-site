# content/

Niche and template records pushed from the data repository.

- `niches/<slug>.json` — one niche per file
- `templates/<slug>.json` — one template per file

While a folder has no `.json` files the site shows its built-in demonstration records.
As soon as one record is pushed, the demo set for that type is replaced.

Schema, rules and the sync workflow: see `CONTENT-INTEGRATION.md` in the repo root.
